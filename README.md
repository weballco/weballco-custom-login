🇮🇷 راهنمای فارسی

ویژگی‌ها:
- طراحی مدرن: افکت شیشه‌ای (Glassmorphism) و ذرات معلق در پس‌زمینه (Particles)
- کاملاً واکنش‌گرا: بهینه‌سازی شده برای نمایش در دسکتاپ و موبایل
- قابلیت‌های کاربردی: دکمه نمایش/پنهان‌سازی رمز عبور و مدیریت خطاهای ورود
- سفارشی‌سازی: استفاده از لوگو و برندینگ اختصاصی وب‌آل‌کو

نحوه نصب و استفاده:
۱. کدهای این ریپازیتوری را دانلود کرده و در یک پوشه زیپ به نام weballco-custom-login قرار دهید.
۲. پوشه را در مسیر wp-content/plugins/ هاست خود آپلود کنید.
۳. به پنل مدیریت وردپرس رفته و از بخش افزونه‌ها، افزونه را فعال کنید.

🇬🇧 English Guide

Features:
- Modern UI: Glassmorphism design with animated background particles.
- Fully Responsive: Optimized for both desktop and mobile devices.
- User-Friendly: Password toggle (show/hide) and custom login error handling.
- Branded: Tailored for WebAllCo identity and visual style.

Installation:
1. Download the code from this repository and place it in a Zip folder  named weballco-custom-login.
2. Upload the folder to your site's wp-content/plugins/ directory.
3. Navigate to your WordPress Admin panel > Plugins, and activate it.

---

Tech Stack:
- PHP (WordPress Plugin API)
- CSS3 (Variables, Flexbox, Animations, Backdrop Filter)
- JavaScript (Vanilla JS for DOM manipulation)
